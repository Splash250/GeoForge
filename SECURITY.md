# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in GeoForge, report it privately
through the `Splash250/GeoForge` repository security process. If repository
security advisories are unavailable, contact a project maintainer through the
private maintainer contact published for the repository. Do **not** create a
public GitHub issue.

Use upstream Geoman security or contact channels only for upstream package
behavior that reproduces outside this fork.

This keeps GeoForge-specific security handling with the GeoForge maintainers
while preserving the upstream route for upstream-only vulnerabilities.
