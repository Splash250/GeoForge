# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this Sewergy fork, report it
privately through the Sewergy project support process for the repository that
consumes `@sewergy/maplibre-geoman`. Do **not** create a public GitHub issue.

Use upstream Geoman security or contact channels only for upstream package
behavior that reproduces outside this fork.

This keeps fork-specific security handling with the consuming Sewergy project
while preserving the upstream route for upstream-only vulnerabilities.
